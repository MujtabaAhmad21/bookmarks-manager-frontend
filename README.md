# Bookmarks Manager — Frontend

Generated by the Fista Digital FTE. Next.js (App Router) application styled with
Tailwind CSS, calling the backend through a typed client generated from its
OpenAPI schema (see `lib/api/`).

## Run locally

```bash
npm install
npm run dev
```

`NEXT_PUBLIC_API_URL` must be set (see `.env.example`) — Next.js inlines it into
the build at build time, so it must be present before `npm run build`, not just
at runtime.
